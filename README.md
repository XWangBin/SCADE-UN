# SCADE-UN
﻿
**Unsupervised hyperspectral fusion from mosaiced and panchromatic measurements**,

 
SCADE-UN is a research project on reconstructing a high-resolution hyperspectral image from a spectrally mosaiced observation and a co-registered panchromatic (PAN) image. These measurements provide complementary spectral and spatial information, while leaving the reconstruction underdetermined.

 
We investigate a physics-guided unfolding approach that brings together measurement consistency, sensor-response estimation, and learned spatial–spectral regularization.
